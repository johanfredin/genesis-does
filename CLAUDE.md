# genesis-does

Mega Drive/Genesis homebrew repo using SGDK 2.13.

## Layout
- `src/` — common C libs not part of SGDK; headers go in `inc/`
- `assets/` — common images/sprites/etc
- `projects/` — POCs and more serious attempts; each project is self-contained

## SGDK reference
When looking at SGDK sources, use the GitHub repo (github.com/Stephane-D/SGDK), not the local copy at `/home/johan/IdeaProjects/SGDK`.
